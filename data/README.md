# FERA Data

This directory contains datasets used by FERA for model development,
evaluation, and research.

## Structure

- aw/ — Original downloaded datasets. These files must not be modified manually.
- processed/ — Datasets generated by FERA preprocessing pipelines.
- external/ — Supplementary or reference datasets.

## Data policy

Raw datasets are not committed to the repository unless their license
and size explicitly permit redistribution.

Each external dataset used by FERA must document:

- Source
- Dataset name/version
- License
- Citation
- Download/retrieval method
- Relevant features and target
- Known limitations
- Preprocessing performed by FERA
